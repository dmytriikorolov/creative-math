# M3.2 side-grid coordinates and row launch — 2026-11-04

User reported zigzag grid lines at the rounded side and wanted simultaneous row starts
restored alongside continuous launches. Also requested a full M3 handoff for ChatGPT.

## Implemented

The fragment shader previously applied asin to interpolated Float x near the vertical
return tangent, where its derivative becomes unbounded. Small position/interpolation
errors are amplified into grid-coordinate artifacts. Rounded mesh vertices now evaluate
a stable atan2(q,sqrt(h)) angle in Double, store it in unused UV.z and interpolate it
directly in the shader. Existing vertex stride, buffers, caches and passes are retained.
The numerical surface and geodesic equations are unchanged. GPU visual confirmation
remains pending; source/CPU tests cannot establish the final rendered appearance.

Start together as a row defaults on in continuous mode. The first row uses exact user
starts with no jitter. Subsequent escaped slots relaunch with the existing staggered
seeded variation. Turn this option off for staggered initial launches; turn continuous
off for a single simultaneous comparison. Restart reconstructs the original beam instead
of restarting a recycled slot's varied configuration. No active track is replaced merely
to create a new launch.

Created [the full M3 report](../M3_STATUS.md), covering implemented controls/models,
M3.1/M3.2 acceptance gaps, M3.3 not started, verification and deferred scope.
