# M3.2 optional rounded return edge — 2026-11-03

User requested one curved outer join between the upper and lower sheets, with balls
able to travel around it. The option is **Shape → Rounded return edge (+X)**; default
is off. It joins the outgoing +X edge (x=24) over the final four world units. Both

This is spatial surface motion, not gravity/lensing or rolling finite-size ball physics.

## Model and numerical policy

Write r=hypot(x,z), a=throat radius, d=funnel depth, b=d/acosh(10/a).
F=(y+d)^2−g(r)h(x), g=b² acosh(r/a)^2. h is one until x=20, then
1−((x−20)/4)^4 toward x=24. Upper/lower sheets share F=0, with a nonzero
implicit gradient at both throat and return edge. The original shape is unchanged
outside the return strip. acosh² has an analytic continuation through r=a; a local
series stabilizes g and its first/second derivatives during intermediate RK4 stages.

For tangent unit initial velocity, acceleration is
−gradient(F) * dot(v,Hessian(F)*v)/lengthSquared(gradient(F)). This has no tangential
component. CPU Double RK4 uses 1/240, bounded 64-step catch-up, no velocity
renormalization or solver-state projection. Nonfinite states, excessive extent,
>1% energy drift, >0.01 estimated surface-distance residual or >0.01 normal velocity
stop playback. These are fail limits, not stated accuracy guarantees. Angular
momentum is not an invariant of this geometry and is not shown as one.
Only interpolated display positions receive two Newton corrections to F=0.

Mesh uses the existing SurfaceVertex/index layout with shared +X boundary indices.
Renderer retains its cached mesh, one command queue, existing passes and three
persistent trail upload slots. No new per-frame GPU buffer/readback/wait. The
previous open-funnel solver explicitly rejects the rounded model to prevent a
shape/solver mismatch. Lorenz, static M2 and Torus remain separate paths.
