## Architecture notes

The Swift package and Xcode project share the same source files. WorkspaceCore contains only
scene identity and panel geometry; it has no SwiftUI or Metal dependency. The Xcode app embeds
WorkspaceCore as a framework. The package links it into the executable.

MTKView owns its drawable; its coordinator retains the renderer, which owns one command queue
and one render pipeline. No per-frame geometry buffers or CPU readbacks. Three fixed vertices
are emitted by vertex ID in clip space (+Y up), with drawable-aspect correction. Fragment and
clear colors are linear RGB, encoded by an sRGB drawable. Runtime shader compilation occurs
once per viewport creation. Drawing is on demand; there is no simulation clock or camera yet.
No interface animations are introduced, including during drag/snap.
