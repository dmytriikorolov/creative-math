# M3.2 reference curvature, continuous launches, centered trails — 2026-11-04

User supplied a two-sheet wormhole reference with a broad semicircular outer return,
and requested continuous launches, optional randomness, and trails meeting ball centers.
The previous quartic connector was rejected in visual review. M3.2 is not accepted.

## Implemented

- Keep the 72-unit field and original funnel outside the return strip. Replace the
  quartic cap with a near-elliptical section, whose width follows the sheet separation.
  Blend the approach with C4 smoothstep; solver/mesh use the same analytic surface.
  See architecture.md for the formula. Rounded render meshes use 256 angular columns;
  wireframe spacing follows angle around the return rather than squeezing at its tip.
- Continuous launches default on, with speed 2×. A bounded pool launches a waiting ball
  every two simulation units. Recycle only escaped slots, after a delay; never remove
  surviving particles to make room. A full surviving pool suspends new launches while
  those particles keep moving. Turn continuous mode off for simultaneous comparison.
- Position/heading variation is seeded and occurs at launch only. Seed/variation are
  editable native numeric controls. Variation zero gives exact user starts; Restart
  repeats the sequence. Single-step, pause and launch scheduling use fixed simulation
  steps, independent of render cadence. Each relaunch resets its trail (no long bridge).
- Center the shaded ball on the trajectory head rather than lifting only the sphere.
  Preserve sphere shading/depth and the existing Torus point-marker path. Waiting
  balls are hidden; following releases a hidden/recycled selection.

No new GPU formats, buffers, passes or per-frame readbacks. No M3.3 work.
